# 🚀 Space Shooter Game

A 2D space shooter game built with **Python** and **Raylib**. Control your spaceship, shoot bullets, and take on enemies in this arcade-style game.

## 🎮 About the Project

Space Shooter Game is a Python game development project created using Raylib for graphics and game rendering. The project explores the fundamentals of 2D game development, including player movement, shooting mechanics, and real-time input handling.

## ✨ Features

- 🚀 Control the player using the arrow keys.
- 🔫 Shoot bullets using the Space key.
- 🎮 Real-time keyboard input.
- 🖥️ 2D graphics and rendering with Raylib.
- 🐍 Game logic implemented in Python.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Graphics Library:** Raylib
- **Python Binding:** pyray, if used by the project

## 📥 Installation

### Prerequisites

Make sure you have the following installed:

- Python 3
- Git
- The Raylib Python binding used by this project

### 1. Clone the Repository

```bash
git clone https://github.com/Pavan-Adapa/Space-Shooter-Game.git
```

### 2. Navigate to the Project Directory

```bash
cd Space-Shooter-Game
```

### 3. Install Dependencies

If the project includes a `requirements.txt` file, install the dependencies with:

```bash
pip install -r requirements.txt
```

Otherwise, install the specific Raylib Python binding required by the project. For example, if it uses `pyray`:

```bash
pip install raylib
```

### 4. Run the Game

Run the main Python file. For example, if the entry-point file is `main.py`:

```bash
python main.py
```

*Replace `main.py` with the actual name of your game's entry-point file.*

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move up |
| ⬇️ Down Arrow | Move down |
| ⬅️ Left Arrow | Move left |
| ➡️ Right Arrow | Move right |
| Space | Shoot bullets |
